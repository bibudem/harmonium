# Logos des sites des bibliothèques

Fichiers SVG de référence, à employer tels quels : couleurs, tracés et proportions ne se
modifient pas. La construction les copie dans `dist/` sous les mêmes noms. La fiche
`site/pages/fondations/identite.html` décrit leur utilisation.

| Fichier | Contenu |
| --- | --- |
| `logo-bibliotheques-horizontal.svg` | Les bibliothèques, signature horizontale |
| `logo-bibliotheques-horizontal-blanc.svg` | Signature horizontale, texte blanc (fond foncé) |
| `logo-bibliotheques-sceau.svg` | Sceau des bibliothèques |
| `logo-universite-montreal.svg` | Logo de l’Université de Montréal (en-tête) |
| `logo-bibliotheques-compact.svg` | Signature compacte |
| `logo-bibliotheques-compact-blanc.svg` | Signature compacte, texte blanc (fond foncé) |
| `logo-studio-bib-horizontal.svg` | Studio•bib, signature horizontale |
| `logo-studio-bib-rond.svg` | Studio•bib, emblème rond |
| `logo-boite-a-outils.svg` | Boîte à outils, emblème |
