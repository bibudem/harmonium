Procédure à l’infinitif : installer le RPV sous Windows

Prérequis : Windows 10 ou 11, et un code d’identification UdeM.

  1. Ouvrir vpn-client.umontreal.ca dans Safari, Chrome ou Firefox.
  2. Sélectionner Télécharger pour Windows.
  3. Lancer le programme d’installation.
  4. Ouvrir Cisco Secure Client.
  5. Saisir vpn-cisco.umontreal.ca dans le champ d’adresse.
  6. Sélectionner Connexion.
  7. Saisir son code d’identification, par exemple p1234567, puis son mot de passe.

Remplacer p1234567 par son propre code d’identification.
